## 上传到 GitHub Pages

1. 新建 GitHub repository
2. 上传所有文件到根目录
3. 打开 Settings
4. 打开 Pages
5. Source 选择 Deploy from a branch
6. Branch 选择 main
7. Folder 选择 root
8. 保存后等待生成链接
